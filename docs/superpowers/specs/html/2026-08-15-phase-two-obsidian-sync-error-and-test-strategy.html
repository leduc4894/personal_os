Phase 2 — Error handling and verification

Failures preserve local content, canonical integrity and retry evidence. Telemetry never contains content, paths, credentials or signed URLs.

Error model

FailureRequired behavior
Offline, timeout, 429 or dependency outageKeep queue and uploaded parts, apply bounded exponential backoff and do not advance the cursor.
Expired access tokenRefresh exactly once; if refresh fails, require login without deleting queued work.
Revoked device or refresh-token reuseRevoke the token family while preserving local files and pending queue state.
Stale baseCapture a conflict; never retry it as a network failure.
Policy deniedStop upload and mark excluded; preserve the local file.
Cursor gap or local invariant mismatchStop incremental pull and require manifest reconciliation.
Hash, size or multipart mismatchAbort the session and return a terminal integrity error; never commit or apply bytes.
Ambiguous commit acknowledgementUse Phase 1 evidence lookup and exact replay; never guess that rollback occurred.
Unknown failureFail closed with a safe error code and no raw provider message.

Verification gates

Migration
Empty upgrade, fixture upgrade and downgrade for every Phase 2 migration.
Domain
Lifecycle, locator uniqueness, tombstone, token rotation, policy revision and conflict races.
Plugin
SQLite crash/restart, queue bounds, missed watcher, cursor gap, atomic apply and echo suppression.
Mobile
No Node/Electron imports; small batches, suspend/resume and uninterrupted local editing.
Contracts
OpenAPI snapshot, generated TypeScript compile, stable error mapping and policy fixtures.
Integration
PostgreSQL, R2 and Temporal for create/update/rename/move/delete/restore.
End-to-end
Two devices, duplicate/out-of-order events, conflict, policy transition and remote apply.
Web Admin
Playwright login, TOTP, device approval/revoke and exclusion publication.
Security
Leak scanning, cross-device denial, revoked credential and malicious locator/path cases.
Real device
Test Vault on Obsidian Desktop and Mobile with a sanitized result manifest.
