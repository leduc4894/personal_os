Phase 2 — Dependency-ordered vertical slices

The architecture umbrella is not implemented directly. These ten executable slices are grouped into nine independently approved child specs; database, API and plugin work are not separated into long backend-only or client-only waves.

Still shells only: Obsidian plugin, FastAPI composition and Web App. Phase 1 exposes no public sync HTTP contract.

1API runtime and contract foundation

Runnable FastAPI composition root, closed response/error contract, health semantics and deterministic generated-client pipeline. No business schema.

Gate: HTTP contract, reproducible OpenAPI and Web/plugin client compile.

2Login, device and minimal Admin

Password/TOTP session, browser device approval, SecretStorage token rotation and device management.

Gate: login → approve → refresh → revoke.

3Server-owned exclusions

Rules/evaluations, preview and publish UI, signed snapshot and backend recheck.

Gate: denied file reaches neither upload nor projection intent.

4Small-file create and update

SQLite journal, ≤16 MiB API upload, Phase 1 publication/read composition and exact replay.

Gate: offline save reconnects and commits once.

5Locator lifecycle

Stable rename/move history, tombstone/restore and lifecycle projection intents.

Gate: all six event types preserve source identity.

6Cursor, pull and atomic apply

Paginated events, contiguous cursor, verified download, temporary write/rename and echo suppression.

Gate: remote edit applies once without loss.

7Manifest reconciliation

Offline registration, checkpoint-bound pages, deterministic actions, gap and repair flows.

Gate: missed watcher and lost SQLite recover without duplicates.

8Multipart and mobile resilience

Staging sessions, presigned parts, suspend/resume, verification/promotion and exact cleanup.

Gate: interrupted binary upload resumes on real mobile.

9Conflict Inbox and resolution

Verified candidate capture, three-way text merge, binary choice and stale-resolution recheck.

Gate: two-device races never silently overwrite.

10Acceptance and operations

Cross-platform E2E, real devices, security scans, runbooks, schema recovery and final handoff.

Gate: every Phase 2 acceptance passes on one commit.
