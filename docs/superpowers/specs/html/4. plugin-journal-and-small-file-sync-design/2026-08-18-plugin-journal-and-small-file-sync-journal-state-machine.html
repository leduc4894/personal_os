Phần 2 — SQLite journal schema và state machine

SQLite là local journal có quota, không phải canonical cache và không lưu raw file bytes.

Tables

journal_meta

Schema version, dirty generation, reconcile_required, persistence generation đã xác minh.

local_files

Local file key, normalized path, nullable backend source ID, observed hash/size/media type, base version, policy revision.

journal_events

Event ID, idempotency key, create/update intent, frozen fingerprint, state, attempt count, next retry, safe error, operation ID.

journal_attempts

Bounded attempt history: time, closed outcome, request ID; không raw path/content/token.

Persistence + quota

sqlite.gN + manifest

Write bytes → verify SHA-256/size → publish manifest generation → giữ một prior generation đã xác minh.

Bound

Tối đa 10.000 pending rows và SQLite soft cap 64 MiB. Breach đặt reconcile_required, giữ in-flight rows, không chặn editor hay xóa Vault content.
