Phần 1 — Boundaries và ownership

Child 4 chỉ đẩy create/update ≤16 MiB. Canonical authority không rời PostgreSQL/R2.

Vault

Raw bytes, editor changes, create/modify watcher events.

Owner: Obsidian

Plugin journal

SQLite WASM: mapping, fingerprint, intent, retry state.

Not: canonical bytes/tokens

Sync API

Preflight + single-part receive; policy/device/base/idempotency checks.

Owner: FastAPI/domain

Canonical state

PostgreSQL source/version/event; R2 immutable bytes.

Owner: backend

Vault → journal → preflight → stream → verified receipt → canonical commit

Included now

  • Watcher + explicit Sync existing files.
  • Create/update for policy-allowed regular files ≤16 MiB.
  • Offline durable queue, retry, exact replay.
  • Policy/device/token enforcement.
  • Blocked size/policy/conflict/lifecycle states.

Explicitly later

  • Rename/move/delete/restore + locator/tombstone (child 5).
  • Cursor pull, remote apply, manifest repair (child 6).
  • Multipart above 16 MiB (child 7).
  • Conflict UI/resolution (conflict child).
