Phần 6 — UX tối thiểu và vận hành

Queue minh bạch, không có thao tác upload toàn Vault ngầm.

Status

ReadySyncingOffline — queuedLogin requiredPolicy blockedReconcile required

Plugin hiển thị số event theo queue; UI local có thể hiển thị file người dùng thao tác, nhưng telemetry/log không chứa path, content, token hoặc hash.

Commands

  • Sync now: chạy một foreground queue pass cho event đủ điều kiện.
  • Sync existing files: yêu cầu xác nhận, rồi quét snapshot theo batch.

Không có auto scan hoặc nút “sync everything” ngầm.
