Phần 5 — Policy, privacy và lifecycle boundary

Policy fail-closed bảo vệ Vault; lifecycle mutation chưa thuộc child 4.

Policy gate

Capture và preflight đều evaluate snapshot cục bộ. excluded hoặc indeterminate chuyển event sang excluded_policy, không upload và không retry.

Preflight mang verified policy revision; server kiểm tra lại. Server trả excluded cũng là terminal safe state. Chỉ snapshot hợp lệ mới cho phép re-evaluate event.

Privacy

SQLite giữ local path và metadata cần cho sync, không giữ file bytes, access/refresh token, raw policy rule hay telemetry nhạy cảm. Log/metrics không chứa path, hash, payload hoặc token.

Identity

local_file_id chỉ ổn định trong plugin. Tạo source mới chỉ commit source/source_version sau khi server nhận và xác minh bytes; receipt mới trả source_id và version. Client không mint canonical ID.

Deferred work

Child 4: phát hiện file mất, rename, move, delete hoặc restore thì đánh dấu deferred_lifecycle và ngừng network mutation cho thực thể đó.

Child 5: locator, tombstone và lifecycle mutation. Child 4 không tự coi path mới là create, không rebind path, không tombstone và không xóa local file.

Conflict UI: blocked_conflict không retry, overwrite hoặc tự tạo bản sao; giữ metadata để xử lý sau.
