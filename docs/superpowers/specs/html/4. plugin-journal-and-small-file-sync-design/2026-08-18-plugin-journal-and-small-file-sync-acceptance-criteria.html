Phần 7 — Acceptance criteria và test matrix

Mỗi behavior phải có test thất bại trước khi implementation thay đổi nó.

NhómĐiều kiện hoàn thành
Portable persistenceDesktop/mobile cùng SQLite WASM + DataAdapter; hỏng lúc ghi manifest phục hồi generation đã xác minh trước, không mất queue.
JournalSave liên tiếp trước preflight coalesce; save sau fingerprint freeze tạo successor; ngưỡng 10.000 event / 64 MiB đặt reconcile_required mà không chặn Vault.
Giới hạn file≤ 16 × 1024 × 1024 bytes dùng single-part; lớn hơn một byte thành blocked_size, không retry mạng.
API integrityChỉ commit source/version sau full size/SHA-256 verification; stale base thành blocked_conflict; bytes thay đổi trong upload không commit fingerprint cũ.
IdempotencyMất response rồi replay cùng event/idempotency trả receipt gốc committed_replay, không tạo source/version thứ hai.
Offline/authOffline, timeout, 429, 5xx giữ queue và chỉ retry foreground; refresh tối đa một lần/lượt; logout/revoke không xóa queue.
Policy/privacyexcluded/indeterminate không rời thiết bị; server deny cũng chặn; log/metrics không có content, path, hash, token hay policy rule.
Lifecycle boundaryRename/move/delete/restore chỉ deferred_lifecycle, không network mutation. Watcher loss/SQLite recovery failure đặt reconcile_required.

Để child sau

Child 5: locator/tombstone lifecycle và conflict UI. Child 6: manifest cursor/reconciliation thật sự. Sau đó: multipart/resumable, R2 Worker, provider fallback/dual-write và client-side encryption/CMK.
