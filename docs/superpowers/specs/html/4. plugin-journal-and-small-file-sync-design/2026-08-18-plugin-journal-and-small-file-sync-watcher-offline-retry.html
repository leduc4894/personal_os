Phần 4 — Watcher, initial scan và offline retry

Không background daemon; editor và nội dung Vault luôn được ưu tiên hơn queue.

Local capture
  1. Plugin đăng ký event create/modify khi load; buffer path có giới hạn giữ event trong lúc SQLite recovery mở database.
  2. Mỗi file chờ ổn định 250 ms, sau đó đọc lại bytes, SHA-256, size, media type và local policy evaluation.
  3. File được phép và không quá 16 MiB tạo journal create/update. Cùng file chỉ coalesce trước preflight; intent đã freeze nhận successor.
  4. Sync existing files là command rõ ràng: quét snapshot file hiện có theo batch, không chạy tự động khi enable hoặc restart.

Offline, timeout, 429 và 5xx giữ queue. Device refresh chỉ xảy ra một lần khi cần. Revoke/reuse giữ queue và yêu cầu đăng nhập lại. Suspend/cancel ghi trạng thái có thể tiếp tục, không phải lỗi terminal.
