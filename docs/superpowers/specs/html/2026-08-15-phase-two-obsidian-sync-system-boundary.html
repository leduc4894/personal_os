Push local change

Journal event → policy preflight → upload and verify → lifecycle transaction → cursor event → acknowledge exact event.

Pull remote change

Poll cursor → compare local/base hash → verified download → temporary file → atomic rename → record apply marker.

Current design decision: Phase 2 completes when canonical bytes and sync state are consistent. A successfully synchronized source is active, but searchability is tracked separately and is not required until Phase 3 registers and executes SourceIngestionWorkflow.
