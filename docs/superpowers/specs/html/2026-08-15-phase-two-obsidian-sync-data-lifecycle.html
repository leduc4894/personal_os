Phase 2 PostgreSQL migrations

Identity and browser auth

web_sessions, device authorization grants, hashed rotating credentials and token-family revocation.

Locator and deletion

source_locators preserves path history; source_tombstones records logical deletion and restore provenance.

Sync correctness

device_cursors and manifest_runs support monotonic pull and reconciliation after watcher gaps.

Upload sessions

multipart_uploads and multipart_parts retain bounded resumable state; completion requires full-object verification.

Conflicts

source_conflicts binds base, remote current and verified local candidate; resolution records the resulting version.

Policy authority

Revisioned policies, rules and evaluations produce a signed plugin snapshot without granting client authority.

Deleting or corrupting SQLite triggers a manifest reconcile. It must never mint a second canonical source merely from path matching.

Concurrency rule

  • Exact replay returns the original event outcome.
  • A stale base never overwrites current state.
  • Text and binary candidates remain referenced through resolution; future GC owns expiry and deletion.

Deliberately absent

  • No last-write-wins.
  • No physical object deletion in a request path.
  • No parser or projection execution in Phase 2.
