Transaction invariants

  • Argon2id verify ngoài locks; credential revision recheck trong short transaction.
  • TOTP row lock serializes replay marker.
  • Grant exchange commits device, family, tokens và audit một lần.
  • Refresh locks family/current token và exact-replays one rotation.
  • Revoke updates device, family, tokens và audit atomically.

Migration and contract gates

  • Named constraints/indexes và deterministic downgrade.
  • Empty upgrade, Phase 1 fixture upgrade, downgrade, reflection tests.
  • OpenAPI snapshot + generated client cùng change.
  • Mỗi public error có một HTTP mapping và safe-detail allowlist.
  • Không R2, Temporal, Redis, Qdrant, Neo4j trong auth transaction.
