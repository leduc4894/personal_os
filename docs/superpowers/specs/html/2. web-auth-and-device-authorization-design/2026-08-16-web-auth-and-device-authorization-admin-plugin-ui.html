Plugin behavior

  • On load: restore SecretStorage và one bounded refresh.
  • Pending grant resume trước expiry.
  • Offline giữ credential và báo recoverable state.
  • Revoked/reuse ghi tombstone không chứa credential, giữ Vault data.
  • Disconnect self-revokes rồi ghi tombstone và xóa settings reference.
