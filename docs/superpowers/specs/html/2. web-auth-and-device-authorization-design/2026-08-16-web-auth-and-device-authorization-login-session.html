Revoke mọi Web session khác nhưng giữ approved plugin devices.

Password policy

  • 15–128 Unicode characters; cho phép khoảng trắng.
  • Không composition rule hoặc periodic reset.
  • Chặn common/known-compromised values bằng offline blocklist.
  • Nâng Argon2id parameters khi successful login nếu hash cũ.

Failure behavior

  • Unknown user và wrong password không thể phân biệt qua response.
  • Throttle bucket lưu HMAC username/source, không raw IP.
  • Expired/revoked session làm browser state bị clear.
  • Logout revoke row trước; xóa cookie không đủ để kết thúc server session.
