Security, privacy and operational behavior

Threats map to enforceable controls, safe signals và fail-closed outcomes.

Credential theft
  • DB chỉ lưu hashes/ciphertext.
  • Plugin dùng SecretStorage.
  • Refresh rotation + reuse detection.
  • Immediate device/family revoke.
Browser attack
  • Secure HttpOnly SameSite cookie.
  • Exact Origin + CSRF.
  • Strict CSP, no third-party scripts.
  • Session rotation.
Brute force / phishing
  • Persisted throttle, generic errors.
  • Visible matching user code.
  • Recent re-auth.
  • No auto-approve/arbitrary scopes.
Telemetry leakage
  • No raw path/query/header/body.
  • No username, IP, token, device name.
  • Closed labels only.
  • Leak sentinels.

Secret and deployment boundary

Exact auth key file

32 random bytes, versioned key ID, HKDF-separated subkeys cho token replay, TOTP AEAD, CSRF, bucket HMAC và recovery hashes.

Trusted proxy

Forwarded headers chỉ từ configured exact CIDRs; nếu không dùng socket peer.

Startup

Missing/invalid key refuses serve; OpenAPI export không đọc secret.

Safe audit and metrics

Audit: known-account login, password/TOTP/recovery lifecycle, device approval/register/revoke và confirmed reuse.

Metrics: counts, closed outcomes, latency, active/revoked counts.

Never labels: username, source address, token ID, device name, code, cookie hoặc session ID.

Correlation: existing server-owned request/trace context.
