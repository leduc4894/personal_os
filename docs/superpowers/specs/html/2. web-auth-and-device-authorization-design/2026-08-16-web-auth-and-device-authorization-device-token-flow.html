Retry-safe invariants

  • Grant exchange exact-replay từ cùng high-entropy polling secret.
  • Refresh response loss không bị hiểu nhầm là theft.
  • Domain-separated keyed PRF derive replay material; DB chỉ giữ hashes.
  • Concurrent exchange/refresh được serialize bằng row lock.

Terminal outcomes

  • Deny/expiry chỉ clear pending onboarding secret.
  • Revoked device không dùng được access token chưa hết hạn.
  • Confirmed reuse yêu cầu browser approval lại.
  • Admin revoke không xóa local Vault hoặc queue.
