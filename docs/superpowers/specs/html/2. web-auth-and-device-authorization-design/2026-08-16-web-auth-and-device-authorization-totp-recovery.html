Stored state

TOTP secret

AEAD ciphertext + nonce + key ID; plaintext chỉ tồn tại trong bounded verification.

Replay marker

last_accepted_time_step update dưới row lock; cùng một mã không thể thắng hai lần.

Recovery codes

Domain-separated hashes; mỗi row có revision và used_at.

Recovery path

Password + one recovery code

Consume đúng một lần và tạo recovery_limited session.

Allowed surface

Session chỉ được thay TOTP hoặc logout; không được device/Admin/password writes.

Completion

Thay TOTP rotate session và tạo recovery-code revision mới. Emergency CLI là đường cuối.

Compatibility

  • RFC 6238 SHA-1, 6 digits, 30-second step.
  • Issuer/account label không chứa path hoặc secret.
  • QR render tại client; response dùng no-store.
  • Clock drift ngoài ±1 step fail safely.

Never allowed

  • Không secret/provisioning URI trong log, analytics hoặc URL.
  • Không redisplay recovery code.
  • Không disable TOTP bằng một old Web session.
  • Không recovery session access tới device/Admin writes.
