Chỉ lưu hash của session ID, device secrets, access/refresh token và recovery codes.

TOTP encryption key đọc từ exact server secret file.

Invariants

  • PostgreSQL là auth correctness authority duy nhất.
  • Credential quyết định user, workspace, device và scope; request body không chọn workspace.
  • Revoke có hiệu lực ở request kế tiếp.
  • Redis không cần thiết cho correctness của auth hay throttle.
  • Next.js và plugin chỉ là clients của generated API contract.

Explicitly absent

  • Không public signup, email recovery, OIDC hoặc passkey.
  • Không JWT hoặc client-trusted token claims.
  • Không auth authority nằm trong Next.js hay plugin.
  • Không raw credential trong database, logs, URL hoặc plugin settings.
