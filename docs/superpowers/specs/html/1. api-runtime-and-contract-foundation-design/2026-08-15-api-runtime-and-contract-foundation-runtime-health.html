Runtime configuration & health semantics

API process có thể sống để báo trạng thái ngay cả khi PostgreSQL tạm unavailable, nhưng chỉ nhận traffic khi canonical schema sẵn sàng.

personal-api serve

Chỉ nhánh serve lazy-import FastAPI/Uvicorn. Các đường --help, --version, invalid syntax và check-runtime giữ nguyên shell boundary, không import framework hoặc mở network.

Local / test

Mặc định 127.0.0.1:8000.

Loopback-first để tránh vô tình expose API trên LAN.

Staging / production

Bắt buộc khai báo KNOWLEDGE_API_HOST và KNOWLEDGE_API_PORT.

Không có implicit public bind.

/api/health/live

  • Unauthenticated.
  • Không thực hiện network call.
  • Xác nhận app/event loop đang phục vụ.
  • Dependency outage không làm liveness fail.

/api/health/ready

  • Unauthenticated.
  • Một PostgreSQL connectivity + Alembic-head check.
  • Deadline toàn probe: 2 giây, không retry nội bộ.
  • DB unavailable → 503 retryable.
  • Schema drift → 503 non-retryable cho tới khi sửa migration.
